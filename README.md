# Byga Calendar Splitter Guide

Static, front-end-only interactive guide for soccer parents.

## Privacy
No backend, analytics, cookies, localStorage/sessionStorage, form submission, or third-party JavaScript. Names/team strings exist only in the current tab to generate code. The Byga URL is never entered into the site.

## GitHub Pages
1. Create a repository such as `byga-calendar-guide`.
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. In the repository open **Settings → Pages**.
4. Configure GitHub Pages to publish the site. For a simple static site, publish the repository root or use GitHub Actions.
5. The project URL is normally `https://YOUR-USERNAME.github.io/byga-calendar-guide/`.

No build step or dependencies are required.
