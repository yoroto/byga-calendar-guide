SOCCER PARENT TOOL

Give each kid their own soccer calendar color.

Generate a Cloudflare Worker that splits one combined Byga calendar into separate live Apple Calendar feeds.

🔒 Private by design. No backend, analytics, cookies or storage. What you type stays in this browser tab. Refresh and it is gone. Your Byga URL is never entered here.

Add your players

Enter each kid's name and a unique team-name fragment as it appears in Byga.

Copy your generated Worker code

The code updates as you type. The number of players is unlimited.



Get your Byga URL
If Byga gives you webcal://…, change only the beginning to https://…. Test the HTTPS URL in your browser; it should open/download an ICS file.
Do not put the Byga URL into this website or into your GitHub repository.


Create the Cloudflare Worker
  1. Go to Build → Compute → Workers & Pages.
  2. Create a Worker using Start with Hello World.
  3. Name it, e.g. byga-calendar, and deploy.
  4. Open Edit Code, replace Hello World with the generated code above, and deploy.


Add the Byga URL privately
Worker → Settings → Variables and Secrets → Add.
Type
Secret
Name
BYGA_URL
Value
Your HTTPS Byga URL


Test your feeds
Open your Worker's base URL; it lists all generated feeds. Then test each feed in a browser.
HTTP 403 from Byga?
The generated code already includes the browser-like request headers that fixed this in our real setup. Also make sure BYGA_URL starts with https://, not webcal://.


Add feeds to Apple Calendar
  1. Mac Calendar → File → New Calendar Subscription…
  2. Paste one player's Worker URL.
  3. Name it e.g. Jimmy XF and choose that child's color.
  4. Set auto-refresh to Every 15 minutes.
  5. Repeat for each player and optionally Others.
  6. Once verified, disable the original combined Byga subscription to prevent duplicates.
Already have a Jimmy iCloud calendar? Keep Jimmy XF separate but give both the same color. Don't import the ICS: importing is only a one-time copy.


No Mac needs to stay running
Whenever Apple refreshes a feed, Cloudflare fetches the latest Byga ICS and filters it on demand. Original event blocks and UIDs are preserved so updates remain updates.


When a kid changes teams
Change only that player's match value in the Worker configuration. Keep their path unchanged, so the Apple Calendar URL stays the same.


Privacy
This static site has no backend, analytics, cookies, localStorage, sessionStorage, forms, or third-party JavaScript. Player data exists only in this page's current JavaScript memory to generate code. Closing or refreshing the page clears it. Your Byga subscription URL is deliberately never collected.
